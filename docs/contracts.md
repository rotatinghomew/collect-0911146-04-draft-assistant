# 草稿界面契约

当前 browser_probe 只读取已登录草稿的修订和物料行，quote.py 提供已核准报价，尚无自动写入及合流逻辑。
草稿 D-701 的 line_id 是业务行身份，description 可以重复，界面顺序不提供身份含义。
每行有 quantity、price、tax、note；tax=exempt 时展示 exemption，未填用途不能保存。
页面输出草稿修订号，每次保存携带当前修订，过期修订返回冲突且不落盘；422 校验失败不改变修订。
#notice 的可见文案和 data-saved 表示最近一次保存响应，不代表未保存的其他行已经生效。
门户支持人工在另一窗口保存；重新读取按钮显示当前服务端草稿。关掉浏览器会丢失未保存输入。
handoff 消费字段事件，不接受会话秘密。最终提交是单独按钮，不能作为草稿保存动作。

portal.py 提供持续运行的同源服务；package.json 的 start 只是该 Python 入口的别名。
GET /session 对未登录访问返回 authenticated=false，不包含草稿内容；草稿读取、保存和最终提交仍需会话。
页面先判断会话再加载草稿，避免把正常的未登录访问作为失败请求；登录和刷新不改变修订或提交次数。
